# 🧴 Cosmetic Product Analysis

## Overview

This is a personal project where I analyzed a dataset of cosmetic products to uncover patterns in product status, chemical usage, and company-level trends. I used Python for data cleaning and analysis, and Power BI to build an interactive dashboard. The goal was to sharpen my data skills and apply them to a real-world-style dataset.

---

## Files

- `cosmetic dataset.xlsx`  – Cleaned dataset for quick insights.
- `cosmetic.ipynb`         – My Jupyter Notebook where I did all the cleaning, analysis, and visualizations.
- `cosmetic_analysis.pbix` – Power BI dashboard with key insights visualized.

---

## Tools Used

- **Python (Pandas, Matplotlib, Seaborn)** – For data analysis and visualizations
- **Power BI** – For building an interactive dashboard
- **Excel** – For initial review of the dataset

---
## 🎯 Key Objectives

- Clean and structure unorganized cosmetic product data.
- Explore product statuses (active/inactive) over time.
- Analyze chemical ingredients and their frequency across products.
- Present findings using both Python visualizations and an interactive Power BI dashboard.

---

## 🔍 Highlights & Insights

- Identified trends in product discontinuation and activity status.
- Analyzed chemical usage patterns and flagged frequently occurring ingredients.
- Filtered products by company and category for deeper comparison.
- Created visual dashboards to support data-driven decision making.

---

## How to View the Project

1. Open `cosmetic.ipynb` in Jupyter Notebook to check out the code and charts.
2. Open `cosmetic_analysis.pbix` using Power BI Desktop to view the dashboard.
